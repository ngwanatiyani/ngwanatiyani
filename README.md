## Project Overview

D6 Food Bulk connects NSFAS students with wholesalers offering student rates. Students can create food bulks that suit their needs and budgets. The current service area covers CPUT residences at the Cape Town Campus.

## 2. User Stories and Tasks

| ID | User story | Main tasks |
|---|---|---|
| **US-01** | As an NSFAS student, I want to view student-rate food bulks so that I can find affordable options. | Display products, prices and availability |
| **US-02** | As a student, I want to customise a food bulk so that it suits my needs and budget. | Build item selection and update the package |
| **US-03** | As a student, I want to see my total cost so that I can make an informed decision. | Calculate totals and test price changes |
| **US-04** | As a wholesaler, I want students to see my available products so that I can serve the student market. | Present product details and availability |

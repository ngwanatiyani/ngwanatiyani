# Sprint Backlog Evidence

The Sprint Backlog below reflects the six current development sprint lists on the [D6 Food Bulk Trello board](https://trello.com/b/b3Akuvef/d6-food-bulk). The board also contains closed early-planning lists, which are separate from this Sprint 1–6 development sequence.

Each backlog item links directly to its Trello card. No completion status is claimed here; this page records the work and assignments currently shown on Trello.

**Sprint focus:** Establish student account access through registration, login, profile management, password recovery and secure data handling.

> **User Story:** As a student, I want to create an account and log in securely so that I can access the D6 Food Bulk platform and place grocery orders.
